# Star Wars API

A simple REST API built using Node.js and Express that returns a list of Star Wars characters and the movies they appeared in.

## Technologies Used

- Node.js
- Express.js
- JavaScript
- JSON
- Postman
- Git and GitHub

## Features

- Get a list of Star Wars characters
- Get a specific character by name
- Returns data in JSON format
- Handles characters that are not found
- Tested using Postman
